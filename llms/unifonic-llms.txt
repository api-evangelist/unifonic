# Unifonic

> Unifonic is a Saudi Arabia-based customer engagement / CPaaS platform (backed by SoftBank Vision Fund) offering SMS, WhatsApp, voice, push, and OTP verification APIs plus conversational AI products for the Middle East and beyond. REST APIs authenticate with an AppSid application credential; docs are published at docs.unifonic.com with official OpenAPI 3.0 documents behind each API reference.

Generated by API Evangelist (2026-07-21, method: generated) from apis.yml and the artifacts in this repository — Unifonic publishes no /llms.txt of its own.

## APIs

- [SMS API](https://docs.unifonic.com/articles/api-documentation/sms-api): Send, schedule, and query SMS messages (base https://el.cloud.unifonic.com/rest/SMS)
- [Authenticate API](https://docs.unifonic.com/articles/api-documentation/unifonic-authenticate-1): OTP verification over SMS, WhatsApp, voice, and email (base https://authenticate.cloud.api.unifonic.com/services/api/v2)
- [Voice API](https://docs.unifonic.com/articles/api-documentation/voice): Calls, IVR, number masking, queues, and call-status webhooks (base https://voice.unifonic.com/v1)
